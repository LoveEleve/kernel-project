# VPC 控制面从零到精通 · 系列规划（README·v4.3）

> **定位**：一套"从 0 开始"的 VPC 控制面教科书。目标——**讲透**四件事：二代（Gen2）｜5.0（Gen3）｜腾讯云控制面整体架构｜业务控制面公认难题。
> **重心声明（防跑偏）**：本系列的"心脏"是 **VPC 控制面本体（Part 二/三/四）+ 分布式问题 / 工程问题 / 业界公认难点（Part 五）**——由 `07-控制面是什么` 立题，`Part 五` 集中攻坚；其余部分是**前置**（Part 一）、**支撑**（Part 六/七）、**实战**（Part 八/九/十/十一）与**复习**（Part 十二）。
> **读者**：零基础起步，终点对标"能独立设计与答辩控制面"。
> **源材料**：`docs/vpc` 34 课 + 总架构图 + 验收卷；`test-good` 材料库（14 场景物证/事故/对照/问答）；`vpc-lab` 教学切片；开源精读（Calico/OVN/cilium/DPDK 对照）。
> **体例**：例子先行 → 原理 → 源码/材料行号 → 带走一句话；每篇自包含。**难题篇统一四段式**：① 现象与代价 → ② 我们的解法 → ③ **业界对照**（Andromeda/AWS/OVN/K8s 怎么做）→ ④ 带走一题。
> **篇数**：**110 篇 + 附录（不封顶）**。拆篇判据：任何一节"为什么/怎么做/坑在哪/怎么验证"有一问讲不透就地拆篇；实验篇按环境实况分"真跑/走读/推演"三档。
> **修订历史**：v1=45 → v2=86 → v3=97 → v4=104 → v4.1=105（实验按环境实况重写）→ v4.2=107（重心校准：核心声明/四段式/+写入可靠性/+兼容演进）→ **v4.3=110（材料反向覆盖查漏：+数据模型推演 +选型权衡 +从零设计演练——07-advanced 五篇全部落位）**。
> **状态**：全部【待写】。
> **阅读路线（防迷路）**：① **顺序线**：01→110；② **主题线**：任选部分直读（篇首给前置提示）；③ **复习线**：终考 → 难题抽背 → 场景复述。共同前提：先过 01-10 地基。
