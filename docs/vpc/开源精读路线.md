## 二、课程表

### 第一批：控制面 ↔ agent 全链（两个对象，**已核验可开读**）

**第 1 课 · kube-ovn：「一条子网的一生」**

关键路径（全部实仓核验）：
```
kube-ovn/cmd/cmdmain.go                    # 多二进制分发（路由到各子命令包）
  → kube-ovn/cmd/controller/cmdmain.go     # 29 行薄入口
  → kube-ovn/pkg/controller/controller.go  # 1821 行；Run(ctx) @1200 —— 控制面主循环
  → kube-ovn/pkg/ovs/ovn-nb-*.go           # NB 翻译层（per-resource 一族）：
    ovn-nb-logical_router.go / ovn-nb-logical_router_route.go / ovn-nb-acl.go / ovn-nb-address_set.go …
  → kube-ovn/pkg/daemon/controller.go      # 1133 行；Run(stopCh) @1053 —— 节点侧 agent
  → kube-ovn/pkg/daemon/flow_rules_linux.go / gateway_backend_linux.go  # 下发到 OVS
```
对照卡锚点：controller 写 OVN NB（SoT = OVN DB）↔ 我们 sdn_oss 写 MySQL+ZK 出树；
daemon ↔ vpc_agent（"哪个子网/端口归我管"的判定机制不同）。

**第 2 课 · calico felix + typha：「agent 的 delta 与 fan-out」**

关键路径（全部实仓核验）：
```
calico/felix/cmd/calico-felix               # 入口
  → calico/felix/calc/async_calc_graph.go   # 260 行 —— 计算图（增量推导）
  → calico/felix/calc/active_rules_calculator.go 等 calculators 一族
  → calico/felix/dataplane/linux/int_dataplane.go # 3317 行 —— 下发引擎 + full resync
calico/typha/                               # DESIGN.md + pkg/ —— fan-out 代理
```
对照卡锚点：delta + 周期 full resync ↔ vpc_agent Inspector 对账 + 全量兜底；
typha 的读放大治理 ↔ agent-broker。

## 三、每课模板（与讲解方式.md 同构的五段式）

1. **它干了什么**——一个具体例子（输入/输出，先人话）
2. **链路走查**——file:line 级（每引一处核一次）
3. **设计推导**——为什么长这样（约束 → 决策 → 代价）
4. **对照卡**——它 vs 我们（机制 / 代价 / 我们为什么不同）
5. **验收题**——3-5 道（问题分类学出题；答完写回进度看板）
