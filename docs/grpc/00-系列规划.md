## 二、抓核心原则（本系列约束）

1. **只做 🔴 7 域**：G-1/G-2/G-3/G-4/G-5/G-7/G-8；🟡 G-6/G-9 压缩进 08，G-10 一句带过；
2. **例子先行**：每篇先跑实验看现象，再进源码（引用片段逐字 + file:line 证据）；
3. **证据纪律**：脚本 + evidence 日志 + 逐篇深审（沿用 Redis/Tomcat/Dubbo 系列标准）；
4. **不做**：xDS/RLS、TLS 细节、okhttp/android/census、GCP 观测、benchmarks（见 §五边界）。
