# Tomcat Learning Checklist v1

> 用途：学一课勾一课。**一次只学一课**。
> 🎯 最终产出：`architecture-map`（组件图 + 请求流转 + 面试速记卡）；现有 `00~14` 面试文档作为**产出物/话术稿**保留，不作为教材。
> 版本口径：Tomcat **10.1.34**（源码树，同时携带官方文档树 `webapps/docs/`）；内嵌运行版本 = Spring Boot 3.2.5 自带 Tomcat 10.1.20（机制一致）。
> ⚠️ 按**类名**找，不按行号找（行号随版本漂）。

---

## 0. 三层阅读约定（每课都按这个尺度）

| 层 | 内容 | 你要做的 |
|---|---|---|
| **结论** | 每课开头"要掌握的 N 条" | 读懂 + 能复述 |
| **推导** | 机制说明、图示、实验 | 读懂即可，**不记** |
| **查阅** | 类名、参数、边缘场景 | **跳过**，用时回来查 |

> 🚫 硬规矩：
> 1. **概念课（L01~L06）不给源码阅读任务、不出现行号**；为解释概念允许最小片段与类名（作为术语）；源码主干只在 Stage 3 讲（按类名）；
> 2. 每课必须有"要掌握的 N 条"开头与 Self-Test（**参考答案直接给出**）；
> 3. 提问方式：**直接说编号**，如「L01-3.2 没懂」；
> 4. 每课写完后做一轮深度 review（官方原文逐字 + 事实验证 + 风格一致性），记录在 `review-log.md`。
