## 实验 1：管道（pipe）

### 匿名管道

```
pipe(fd[2])：fd[0]=读端，fd[1]=写端
  → 父子进程通信（单向）
  → 内核缓冲区（默认 64KB）
  → 写满阻塞写端；读空阻塞读端
  → 只能用于有亲缘关系的进程（fork 继承 fd）
```

### 命名管道（FIFO）

```
mkfifo /path：创建命名管道（文件系统可见）
  → 无亲缘关系进程可通信
  → 实测：prw-rw-r--（p=管道文件）
  → 读写：cat > fifo &（写）；cat fifo（读）
```

### P9 追问链

- **Q：匿名管道限制？** → 只能父子进程（fork 继承 fd）；单向
- **Q：命名管道怎么用？** → mkfifo 创建；任意进程 open 读写
- **Q：管道缓冲多大？** → 默认 64KB（/proc/sys/fs/pipe-max-size 可调）

## 实验 2：共享内存（最快的 IPC）

### 机制

```
共享内存：多个进程映射同一物理内存
  → 最快 IPC（无内核拷贝，直接读写）
  → 需要同步（信号量/互斥锁）

实现：
  System V：shmget/shmat/shmdt
  POSIX：shm_open/mmap
  mmap：映射 /dev/shm（内存文件系统）

/dev/shm：tmpfs（内存文件系统，共享内存载体）
  → ls /dev/shm 查看共享内存对象
```

### 为什么最快

```
管道/消息队列：进程A→内核缓冲→进程B（两次拷贝+系统调用）
共享内存：进程A↔物理内存↔进程B（无拷贝，直接读写）
  → 省内核拷贝+系统调用
  → 代价：需要同步（信号量/锁）
```

### P9 追问链

- **Q：共享内存为什么最快？** → 无内核拷贝（直接读写同一物理内存）
- **Q：共享内存有什么代价？** → 需要同步（信号量/锁保护）
- **Q：怎么查看共享内存？** → ipcs -m / ls /dev/shm

## 实验 3：信号量（Semaphore）

```
信号量：计数器（P 操作减/V 操作加）
  → 控制并发访问资源数量
  → P（wait）：sem-- （<0 则阻塞）
  → V（signal）：sem++ （唤醒等待者）

应用：
  限制并发数（如连接数限流）
  同步进程（生产者-消费者）
  与共享内存配合（保护共享内存）

ipcs -s 查看信号量（实测：无活跃信号量）
```

### P9 追问链

- **Q：信号量和互斥锁区别？** → 信号量=计数（限制 N 个并发）；互斥锁=二元（1 个）
- **Q：P/V 操作？** → P=wait（sem--，负则阻塞）；V=signal（sem++，唤醒）

## 实验 4：eventfd（事件通知）

```
eventfd：内核事件计数器（Linux 2.6.22+）
  → 轻量事件通知（比管道高效）
  → 读写计数器（非数据）

应用：
  epoll 事件通知（eventfd + epoll）
  线程间唤醒（替代条件变量的轻量方式）
  io_uring 完成通知
  systemd/service 通知（sd_notify）
```

### P9 追问链

- **Q：eventfd 和 pipe 区别？** → eventfd=计数器（轻量）；pipe=字节流（有缓冲）
- **Q：eventfd 用在哪？** → epoll 通知/线程唤醒/io_uring/systemd

## IPC 方式对比（P9 高频）

| 方式 | 速度 | 亲缘限制 | 用途 |
|---|---|---|---|
| **管道（pipe）** | 中 | 父子进程 | shell 管道（cmd1 \| cmd2） |
| **命名管道（FIFO）** | 中 | 无 | 任意进程单向 |
| **共享内存** | **最快** | 无 | 大数据量（需同步） |
| **消息队列** | 中 | 无 | 结构化消息（System V/POSIX） |
| **信号量** | 快 | 无 | 同步/限流（配合其他 IPC） |
| **eventfd** | 快 | 无 | 事件通知（轻量） |
| **Socket** | 中 | 无 | 网络/本机（域7 已讲） |
| **信号** | 快 | 无 | 简单通知（kill/signal） |

### P9 追问链

- **Q：最快的 IPC？** → 共享内存（无内核拷贝，直接读写）
- **Q：shell 管道用什么？** → 匿名管道（pipe，fd 继承）
- **Q：跨进程限流用什么？** → 信号量（sem 计数控制并发）
