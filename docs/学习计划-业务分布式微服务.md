## 1. 路线设计：四条线，互相咬合

```
L1 微服务工程线  ── 从 0 搭一套最小微服务（服务侧展开，不含网关）
L2 分布式专项线  ── 对齐权威"分布式 4 主题"（含下一站 Redis），理论→实验
L3 业务域线      ── 电商交易/内容域知识（以 xhs-project 为实证，抽成可跑的最小模型）
L4 计算机内功线  ── 内功 7 主题 80 篇大纲 → 实验驱动（§5：免 sudo 主力 + sudo 窗口 + 机制节点钉证据）
```

**咬合关系**：L1 提供工程底座（Nacos/Feign/Sentinel/事务消息）→ L2 用它在**分布式语义**上做实验（一致性/幂等/对账）→ L3 把分布式语义**落到业务规则**（库存/订单/支付/营销/履约/内容）→ L4 解释"为什么底层是这样"（OS/网络/内存/MySQL）。每条线都必须回链 xhs-project 的真实代码。

## 2. L1 微服务工程线（6 个 lab）

> 目标：把 xhs-project 的"服务侧微服务机制"逐个拆成可跑可观察的最小样例。全部新建在 xhs-demo。

| # | 单元 | lab 模块 | 实验要点（含破坏性实验） | xhs-project 落点 |
|---|---|---|---|---|
| L1-1 | 服务发现与配置 | `ms-nacos-lab` | provider 注册/consumer 发现；**杀掉一个实例**看负载均衡重选；配置热更新（@RefreshScope）失败回滚 | 15 服务 Nacos 接入、命名空间隔离、`spring.config.import` 兜底 |
| L1-2 | 声明式调用与客户端负载均衡 | `ms-feign-lab` | Feign 超时/重试矩阵；**轮询 vs 最少连接**在慢实例下的差异；降级工厂（FallbackFactory）触发条件 | `FeignInternalCallInterceptor`、最少连接 LB、30 个降级工厂、NEVER_RETRY |
| L1-3 | 容错与限流（服务侧） | `ms-sentinel-lab` | 流控/熔断/热点参数/系统规则；**规则持久化到 Nacos**；熔断半开恢复实测 | 服务侧 @SentinelResource 用法、网关侧规则（网关部分归另一 AI） |
| L1-4 | 分布式事务（方案对照） | `ms-tx-lab` | 三套最小实现：① 事务消息+本地消息表 ② Seata AT ③ 纯补偿/对账；**注入回查延迟**看一致性 | `OrderTransactionListener`、本地消息表、`LocalMessageRetryJob` |
| L1-5 | 可观测（服务侧） | `ms-observability-lab` | Micrometer 指标埋点；traceId 跨 HTTP/MQ/线程池/异步；**日志 MDC 在池化线程的丢失与修复** | `BusinessMetrics`、`MdcAwareExecutorService`、各服务 actuator |
| L1-6 | 契约与边界防护 | `ms-contract-lab` | 内部令牌（X-Internal-Call）的 fail-closed；**伪造内部头**被网关/服务侧拦截；批量接口上限 | `AccessTokenGuard`、内部端点白名单、batch 接口上限 |

**每单元产出**：lab 源码 + `mvn -pl <lab> spring-boot:run` 一键脚本 + `docs/ms/NN-*.md`（例子先行五段式）+ 实验输出（贴真实日志/指标） + 图谱节点。

## 5. L4 计算机内功线（权威 7 主题 · 80 篇大纲 → 实验驱动）

> **权威对齐**：`规划/内功修炼/`（7 主题 80 篇 = 19+13+12+14+8+7+7，大纲均在 `outlines/{主题}/`；除 07 系统编程外书稿已闭环）。
> **学习模式**：**一篇大纲 = 一个可验证实验**（不重写书稿正文、不给书稿打工）；产出 = 实验记录 + 机制节点补"验证证据" + 面试卡 1 张。
> **机器能力（已实测，决定实验分档）**：
> - ✓ **免 sudo 主力**：gcc/make/strace/ss/ip/dd/openssl；`/proc`+`/sys` 观测（meminfo、net/tcp、smaps_rollup、THP=madvise、dirty_ratio、schedstat）；JVM 侧 async-profiler；THP 走 `madvise` 模式

## 7. 每个学习单元的验收标准（五件套，缺一不算完成）

1. **可跑**：`mvn -pl <lab> spring-boot:run`（或 `scripts/*.sh`）一键起，有真实输出可贴；
2. **文档**：`docs/<topic>/NN-*.md`，遵循**例子先行**五段式（它干了什么→为什么→怎么做/坑→追问→边界），禁止"术语起手"；
3. **回链**：文末必须写"**xhs-project 落点**"（文件:行号 + 与该 lab 的差异说明）；
4. **证据**：破坏性实验必须有"故障→复现→修复→消失"的对照记录（日志/指标/压测数字）；
5. **图谱**：对应知识图谱节点（原理/框架/机制）更新或新建，与 lab、doc 双向链接。
