## 三、前置要求

- MySQL 索引与事务（分片是它的分布式化）。
- Seata 06（"跨系统一致性走事务消息+对账，不上 XA"的语境）。
- XXL-JOB 06（`OrderMappingRepairJob` 补录任务的用法）。

## 四、掌握分级

- **必须掌握**：五步内核；分片键选型论证；两级哈希；绑定表防笛卡尔积；Snowflake 低位偏差；映射表反查。
- **理解思想**：逻辑表 vs 物理表；单用户事务不跨库的设计；"算法切换是破坏性变更"。
- **知道即可**：ANTLR 解析细节；Proxy 模式；ShardingSphere Scaling；基因法。
