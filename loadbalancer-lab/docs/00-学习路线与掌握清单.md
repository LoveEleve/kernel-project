## 一、掌握程度分级

### 🔴 必掌握（生产会用 + 面试必问）

1. **定位与形态**：客户端 LB vs 服务端 LB；SCLB 在调用链里的位置（网关 `lb://`、`@LoadBalanced`、Feign、RestClient 全都走它）
2. **介入方式**：URL 写服务名 → SCLB 自动接管；`LoadBalancerClientFactory` 每个服务一个子上下文；配置优先级（`@LoadBalancerClient` 注解 > `clients.<serviceId>.*` > 全局默认）
3. **名单（`ServiceInstanceListSupplier`）**：装饰器链 / "滤镜"模型；Builder `withXxx`；**7 种预设**（default / weighted / zone-preference / health-check / request-based-sticky-session / same-instance-preference / subset）各自解决什么
4. **挑法**：默认 RoundRobin；Random；权重（**坑**：官方读 `metadata.weight`，Nacos 权重是 `nacos.weight`）；SCA `NacosLoadBalancer`（默认关，开了是权重随机 + 同集群）
5. **名单会变**（生产复杂度都在这）：缓存 TTL 35s（L46 实测：Nacos 1.4s 摘除 vs 网关 35s 窗口）；health-check 主动探测；优雅停机；重试（两种口味：avoid-previous-instance vs same-instance）
6. **排障三视角**：`/lb/distribution` 看分布；`/lb/supplier-chain` 看链；`Connection refused: <实例IP>` = 客户端 LB 直连的实锤

### 🟡 了解（知道有这回事，用到再查）

- **Hint 提示路由**（按请求头 `X-SC-LB-Hint` 选实例——灰度场景）
- **API 版本选择**（A-13；4.1.4 尚未内置，有版本落差注记）
- **X-Forwarded 转换**（A-14；与网关 L48"头传播"呼应）
- **`LoadBalancerLifecycle` + Micrometer 指标**（`loadbalancer.requests.success` / `.failed`）
- **BlockingLoadBalancerClient / 拦截器家族**（Feign、`@LoadBalanced` RestTemplate 走这条——非网关侧）

### ⚪ 翻篇（源码深挖，想抠再看）

- D2 装饰器链 14 个类的逐个实现；D4 权重展开（GCD 归约 / active-expired 双队列）；D5/D7 源码细节
