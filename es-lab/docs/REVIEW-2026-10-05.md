## 三、评审中修正的问题（3 处）

1. **ExternalGte 语义演示预期写错**：原写"v200 重复应拒"——实际 external_gte **相等允许**（幂等重放）；更旧才拒。已修正注释/文档（A04/A05）。
2. **409 异常分类**：`ElasticsearchException` 未捕获（实际包装类型不同）——改为消息含 `version_conflict` 判定 REJECTED。
3. **count 近实时不确定性**：bulk 后立即 count=0——count 端点增加 refresh（演示确定性），并把现象写入 D4 教学。

## 四、验证命令（可复现）

```bash
# 1) 启动 ES（512m 堆）
cd /data/workspace/tools/elasticsearch-8.12.2 && setsid nohup ./bin/elasticsearch > /tmp/es.log 2>&1 &
# 2) 启动 lab
cd /data/workspace/source-code/xhs-demo && setsid nohup mvn -pl es-lab spring-boot:run -q > /tmp/es-lab.log 2>&1 &
# 3) 实验（⚠️ 本地 curl 先 unset http_proxy https_proxy；中文参数用 --data-urlencode）
unset http_proxy https_proxy
curl -X POST http://127.0.0.1:28060/a01/create
curl -G --data-urlencode "text=小红书种草笔记" http://127.0.0.1:28060/a01/analyze
curl -X POST "http://127.0.0.1:28060/a02/bulk?count=100"
curl -G --data-urlencode "q=批量" http://127.0.0.1:28060/a03/match
curl -X POST "http://127.0.0.1:28060/a05/scripted?id=n200"
# 4) 停止（实验后务必停 ES——512m 堆）
kill $(ps -eo pid,args | grep -E "[e]s-lab|[e]lasticsearch" | awk '{print $1}')
```
