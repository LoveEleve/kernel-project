# 配置历史与回滚

## 一、Nacos 如何保存历史

每次配置变更，Nacos 在 `his_config_info` 表中写入一条记录（MySQL 模式）。记录的内容包括：变更前后的完整配置内容、变更时间、操作来源（API/控制台）。

在 standalone + Derby 模式下（当前环境），Derby 是嵌入式的，数据在 Nacos 进程内。重启后 Derby 数据不会丢失（Derby 有本地文件持久化），但性能低于 MySQL。

## 二、历史查询 API

```
# 查询变更历史列表
GET /nacos/v1/cs/history/configs
  ?dataId=nacos-lab.yaml
  &group=DEFAULT_GROUP
  &tenant=sca-lab-dev
  &pageNo=1&pageSize=50
  &search=accurate

# 查看历史项详情（含完整配置内容）
GET /nacos/v1/cs/history/config
  ?dataId=nacos-lab.yaml
  &group=DEFAULT_GROUP
  &tenant=sca-lab-dev
  &nid={历史记录ID}
```

## 三、回滚操作

```
# 方式 A：Nacos 控制台 → 配置列表 → 历史版本 → 点击回滚

# 方式 B：API 操作
# 1. 查询历史 → 拿到历史版本 ID
# 2. 查看详情 → 拿到完整历史内容
# 3. 将历史内容作为新配置发布
POST /nacos/v1/cs/configs
  -d "dataId=nacos-lab.yaml&group=DEFAULT_GROUP&tenant=sca-lab-dev&content={历史内容}"
```

**回滚的本质**：把历史内容作为**新配置**发布——创建了一条新的变更记录，不是删除中间的变更。所以"回滚"本身也是可以被记录的。

## 四、生产注意

- Derby 模式的历史记录持久性依赖于 Nacos 进程不删除 Derby 数据目录
- 生产环境强烈建议用 MySQL 存储（`spring.datasource.platform=mysql`）
- 历史保留天数可配置：`nacos.config.retention.days=30`
