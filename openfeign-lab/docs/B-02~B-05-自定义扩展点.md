# B-02~B-05: 自定义 Feign 扩展点

> 展示 Spring Cloud OpenFeign 的四大扩展点：InvocationHandlerFactory / Contract / Encoder-Decoder / ErrorDecoder
> 实现方式：Capability 模式（包装原生组件，不破坏 Spring MVC 注解处理）

## 一、架构设计

所有自定义扩展通过 **Capability 模式** 注入。Spring Cloud OpenFeign 的 `FeignClientFactoryBean` 自动收集所有 `Capability` Bean，通过装饰器链包装原生组件：

```
CustomCapability.enrich(Contract)         → CustomContract(SpringMvcContract)
CustomCapability.enrich(Encoder)          → CustomEncoder(SpringEncoder)
CustomCapability.enrich(Decoder)          → CustomDecoder(SpringDecoder)
CustomCapability.enrich(ErrorDecoder)     → CustomErrorDecoder(DefaultErrorDecoder)
CustomCapability.enrich(InvocationHandlerFactory) → CustomInvocationHandlerFactory(DefaultInvocationHandlerFactory)
```

## 二、B-02: CustomInvocationHandlerFactory

**文件**: `custom/CustomInvocationHandlerFactory.java`

包装 Feign 的默认 `InvocationHandler`，在每次方法调用时记录：

```
[CustomInvocationHandler] NacosLabClient#health -> OK, cost=12345ns, totalCalls=10, avgCost=1234ns
[CustomInvocationHandler] NacosLabClient#health -> ERROR(FeignException), cost=5678ns, totalCalls=1
```

统计使用 `LongAdder`，线程安全。

**关键代码**：
```java
InvocationHandler delegateHandler = delegate.create(target, dispatch);
return new CustomInvocationHandler(target, delegateHandler);
```

## 三、B-03: CustomContract

**文件**: `custom/CustomContract.java`

包装 `SpringMvcContract`，在接口方法解析时打印日志。不修改任何解析结果。

## 四、B-04: CustomEncoder / CustomDecoder

**文件**: `custom/CustomEncoder.java`, `custom/CustomDecoder.java`

包装 `SpringEncoder` / `SpringDecoder`，在序列化/反序列化前后打印类型和耗时。

**注意**：这两个类只是日志包装器。如果要实现真正的自定义序列化（如 Protobuf），需要直接实现 `Encoder`/`Decoder` 接口并替换 `FeignClientsConfiguration` 中的默认 Bean。

## 五、B-05: CustomErrorDecoder

**文件**: `custom/CustomErrorDecoder.java`

HTTP 错误分类，返回特定异常类型：

| 状态码 | 异常类型 | 说明 |
|:------:|----------|------|
| 404 | `ResourceNotFoundException` | 资源不存在 |
| 429 | `RateLimitExceededException` | 限流（无 Retry-After 头时） |
| 429 + Retry-After | `RetryableException` | 限流（有 Retry-After 头时，委托默认解码器） |
| 5xx | `ServerErrorException` | 服务端错误（无 Retry-After 头时） |
| 5xx + Retry-After | `RetryableException` | 服务端错误（有 Retry-After 头时，委托默认解码器） |
| 其他 | 委托默认解码器 | — |

body 可重复读：通过 `Util.toByteArray()` 提前读取响应体，再用 `response.toBuilder().body(bodyBytes)` 重建可重复读的 `Response` 传给 delegate。

## 六、开关

Capability 在 `CustomFeignConfiguration` 中声明，通过 `@FeignClient(configuration = CustomFeignConfiguration.class)` 启用。该配置类位于 `com.scalab.openfeignlab.extconfig` 包（不在 `@SpringBootApplication` 扫描路径内），因此只对指定客户端生效。

## 七、测试端点

```
GET  /feign/custom-ext-test    → 验证所有自定义扩展点
GET  /feign/custom-ext/echo    → 回显端点
POST /feign/custom-ext/echo-body → 请求体回显端点
```
