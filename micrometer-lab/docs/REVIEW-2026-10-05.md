## 一、版本重定基（重大）

- sca-lab 原基线 = **Boot 3.5.13 / micrometer 1.15~1.17**（文档头部统一写 `main 分支, v1.17.x`）；
- 本 lab 运行时 = **Boot 3.2.5 / micrometer 1.12.5 + simpleclient**（旧版 prometheus registry）；
- 语料 worktree：`code/spring/micrometer-1.12.5`（tag v1.12.5）+ `code/spring/spring-boot-3.2.5`（tag v3.2.5）。

## 二、运行时修复（2 处）

1. **A10SLOController**：`@Timed(serviceLevelObjectives=...)` 是 **1.14+** API → 1.12.5 编译失败；改为编程式 `Timer.builder().serviceLevelObjectives(Duration...)`（1.12.5 存在，编译 ✓）；
2. **application.yml**：Boot 3.2.5 的 `management.observations.annotations.enabled` **默认 false**（元数据 `defaultValue: false`）→ @Timed/@Counted 切面**默认不注册**；已显式 `=true`（否则 A07/A08 无指标）。
